ConvertX source files

Keep index.html, style.css, and script.js in the same folder. Open index.html in a browser.

If the PDF tools cannot reach either CDN, download the exact pdf-lib 1.17.1 file from:
https://cdnjs.cloudflare.com/ajax/libs/pdf-lib/1.17.1/pdf-lib.min.js
Save it as libs/pdf-lib.min.js beside index.html.
